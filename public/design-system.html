10 — Motion & Animation System
Ocean Arms Design System
Foundation
Motion Principles

All animations serve a purpose — revealing content, guiding attention, or confirming interaction. Decorative-only animation is avoided. Reduced-motion preferences are fully respected via @media (prefers-reduced-motion: reduce).

cta-bounce
Hero H1 entrance. Y: 40px → 0 with overshoot at 55% (-8px), settle at 75% (4px). Cubic-bezier(0.34,1.56,0.64,1). Duration 0.9s. Delays: 0.05s, 0.22s, 0.40s, 0.58s, 0.72s for stagger.
pulse-glow
Hero CTA button. Pseudo-element ::after, border 2px rgba(53,128,177,0.55), scales from 1.02 → 1.65 and fades opacity 0.65 → 0. Duration 2.2s ease-out infinite.
scrollMarquee
Horizontal marquee strip. translateX 0 → -50% (doubled track). Duration 28s linear infinite. Pauses on hover (animation-play-state: paused).
Scroll Reveal
All .reveal elements: opacity 0, translateY 32px → visible state via IntersectionObserver. Transition 0.8s cubic-bezier(0.25,1,0.5,1). Threshold 0.05, rootMargin 0 0 -30px 0.
Flip Card
Vision/Mission cards. perspective 1200px, rotateY 180deg on hover. Transition 0.75s cubic-bezier(0.23,1,0.32,1). backface-visibility hidden. Pointer-hover-only media query.
Card Spread
Core Values deck. rAF scroll-scrubbed, lerp(prev, raw, 0.07) for smooth interpolation. txMap / rotMap / scaleMap spread on scroll. IntersectionObserver starts/stops the rAF loop.
Service Rows
Rope Access list items. translateX -28px → 0, opacity 0 → 1 at staggered scroll thresholds (0→0.55). Transition 0.5s with 0.06s delay increments per row.
Timeline Fill
Project Workflow connector lines. scaleY 0 → 1, transformOrigin top. Activated between paired stage thresholds [0.22, 0.38, 0.55, 0.70, 0.86].
Milestone Dots
.ms-dot background transitions 0.45s. Active dot scales to 1.35× and changes BG to --c-deep. .ms-content fades from opacity 0 → 1 over 0.4s.
